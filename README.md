# 실글 원고지 연습장

한국실용글쓰기 시험의 본문 작성 연습을 위한 정적 웹사이트입니다. 제목과 이름 입력은 없습니다. 글을 입력하고 한 장의 가로·세로 칸 수를 각각 10~50으로 설정하면 원고지에 자동으로 배치합니다. 칸을 누르면 해당 배치 이유를 볼 수 있으며 브라우저 인쇄 기능으로 PDF 저장도 가능합니다. 작성 규칙에는 실제 배치 예시를 함께 표시합니다.

사이트: https://jaesin463.github.io/silgeul-wongoji/

## 실행과 배포

빌드 과정이나 외부 라이브러리가 필요 없습니다. 로컬에서는 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 여세요. ES 모듈을 사용하므로 `index.html` 파일을 직접 여는 방식은 브라우저에 따라 차단될 수 있습니다.

GitHub Pages는 `.github/workflows/deploy.yml`로 배포합니다. `main` 브랜치에 `git push`하면 배치 테스트가 실행되고 통과한 사이트 파일만 자동으로 게시됩니다. GitHub Actions의 `workflow_dispatch`로 수동 재배포도 할 수 있습니다.

사이트를 수정한 뒤 이 폴더에서 `git add .`, `git commit -m "변경 내용"`, `git push`를 실행하면 자동으로 재배포됩니다. 배포 결과는 저장소의 Actions 탭에서 확인할 수 있습니다.

## 규칙과 한계

협회 [출제 기준](https://www.klata.or.kr/test/questions)은 원고지 사용법을 평가 항목으로 명시합니다. 그러나 공개된 협회 자료에서 칸별 배치의 세부 규정을 확인하지 못했습니다. 협회 [자료실](https://klata.or.kr/test/pds)의 답안지 예시 상세 게시글은 로그인 권한이 필요합니다. 따라서 이 도구는 **공식 채점 결과나 협회 세부 규정의 완전한 재현을 보증하지 않습니다.**

자동 배치는 사용자가 제공한 「실용글쓰기 실전 대비 노트」 PDF의 29~30쪽을 우선 반영했습니다. 칸 안의 문장 부호 위치와 따옴표·괄호의 줄 끝 처리는 [한국교원대 공개 강의 자료](https://contents2.kocw.or.kr/KOCW/document/2016/gnue/limsonggyu/1.pdf), [원고지 작성법과 문단 쓰기](https://youtu.be/hAinIa14Ry8), [원고지 작성법과 교정부호](https://youtu.be/wEkHoOJpc4M)를 대조했습니다. [영상 1](https://youtu.be/fpk7sg4o3b8)과 [영상 2](https://youtu.be/2BVKCTxY3Gk)도 참고했습니다. 원고지 사용법은 [국립국어원 안내](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=328008)에 따르면 어문 규정 자체로 정해져 있지 않습니다.

현재 구현:

- 첫 문단과 새 문단의 첫 칸 비움
- 한 글자 한 칸, 단어 사이 한 칸 비움
- 줄 끝에 걸린 공백 생략
- 아라비아 숫자 두 자리 한 칸, 숫자 사이의 쉼표·소수점 묶음
- 숫자 뒤 단위 기호 한 칸
- 대문자와 로마 숫자 한 자 한 칸, 소문자 두 자 한 칸
- 마침표·쉼표를 칸 왼쪽 아래에 표시하고 뒤의 입력 공백 생략
- 마지막 칸에서 글자와 함께 쓰는 마침표·쉼표는 글자의 오른쪽 아래에 표시
- 물음표·느낌표 뒤의 입력 공백 유지 (실전 대비 노트에서는 필수가 아님)
- 여는 따옴표 오른쪽 위, 닫는 따옴표 왼쪽 위에 표시하고 곧은 따옴표도 여닫는 모양으로 구분
- 마침표와 닫는 따옴표는 같은 칸, 물음표·느낌표와 닫는 따옴표는 별도 칸
- 여는 괄호·따옴표가 마지막 칸에 홀로 남는 경우에만 다음 줄로 이동
- 줄임표 여섯 점과 줄표는 각각 두 칸에 표기
- 줄 끝에 독립된 문장 부호가 오면 앞 글자와 같은 칸에 표시
- 입력 길이에 따라 여러 장 생성

복합 기호와 길이가 긴 인용 구절의 줄 나눔은 자료마다 처리 방식이 달라 실제 답안지의 안내를 우선해야 합니다. 맞춤법이나 글의 내용은 교정하지 않습니다. 협회 자료실에는 2027년 1월 제123회부터 답안지 뒷면 4문단 변경 양식이 적용된다고 공지되어 있습니다.
